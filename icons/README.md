# ツールアイコン

`./fetch.sh` を実行すると、以下のアイコンを公式配布元から取得してこのディレクトリに配置します。
配置後にサーバを再起動すると、UI のツール名表示がテキストからアイコン画像に変わります。
アイコンが無くても動作します（テキスト表示のまま）。

- `claude.png` — Claude Code のセッションに表示（claude.ai から取得）
- `codex.png` — Codex のセッションに表示（developers.openai.com から取得）
